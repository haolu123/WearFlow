# Stiehl 独立数据集验证：S1 / S2 / S3

## 定位与阶段

用户已授权逐步执行。先进行数据准备、协议冻结、开发侧 smoke 和耗时测量，通过后进行正式固定 100 epoch 实验。本目录独立于 NASA 结果，不覆盖原数据、模型或文章。

本数据目前没有可验证的原始显微测量点标记。所有目标均称“发布标签”（含插值），S3 使用“发布标签初值”，不能据此声称恢复真实瞬时磨损率。来源和全数据单位审计见相邻 external_datasets/stiehl_milling_2023_v3/README.md。

## 冻结的数据协议

- C 按论文解释为累计实际切削接触秒数，保留 H5 中错误的 min 属性原文件；数值不乘 60。VB 微米除 1000 得 mm。
- 用上一已完成记录的三轴外部力信号估计下一记录开始时的 VB。每刀首记录排除；T8 不重置时间起点。不是用当前 run 的完整信号预测其开始状态。
- 力信号固定中央 60% 窗口（不是已核实的纯接触区间）。每轴 9 个时域特征、6 个固定频带功率、质心、谱熵，共 51 维；Welch Hann/2048/1024、使用实际传感器时间轴采样间隔。频带为 [0,250)、[250,500)、[500,1000)、[1000,2000)、[2000,5000)、[5000,10000) Hz。
- 质量检查：有限数、严格递增采样时间、中央窗口至少 2048 点、三轴不能同时常数。无依赖磨损标签的异常点剔除。若出现无效输入，正式训练前须落实冻结的同划分时间基线后备；当前 smoke 直接拒绝无效输入，不静默补值。
- 每个训练划分内按“各训练刀具内绝对 Spearman 的等权均值”排名，前 12 维合计；同分按名称排序。训练有效输入的 1/99 百分位裁剪，再训练均值/标准差缩放。四种网络不分别选特征。
- 预测请求固定 240/480/720 秒。依据仅为开发 T1–T7 间隔中位数 4 秒，取 60/120/180 个典型间隔；不是原始测量间隔。匹配首个 C >= C_origin + H 的发布记录，最多超出请求 30 秒；末端缺覆盖不外造标签。传播使用匹配后的真实 dt。
- 9 外层留一刀具测试；每外层固定留同机床前一把刀（循环）作一次内层验证，其余 7 刀训练。最终用 8 开发刀重训。内层不扫参、不按测试调超参数，固定末轮；单个内层验证只用于可运行性/稳定性诊断，不称完整嵌套交叉验证。
- 主输入不使用 tool ID 或 machine ID。切削工况固定，因此 ODE 是 VB-only 的恒定工况特例；该实验不能独立验证条件变化泛化，也不是留一机床测试。

## 模型与预算

| 模型 | 当前估计 | 未来预测/监督 |
|---|---|---|
| 时间 MLP | C/1000，隐藏 [64,32] | 在目标 C 直接查询 |
| Sensor MLP | 前 12 维力特征 + C/1000，[64,32] | persistence；相邻两次因果预测的线性外推（不强制非负斜率），首点 persistence |
| GPR | 同 Sensor MLP 输入 | 主要报告当前监测 |
| Local | 同 Sensor MLP + rate MLP [32,32] | 当前监督 + 固定 sensor 时的时间偏导/rate 一致性；预测通过 ODE 积分 |
| Integral | 与 Local 完全同初始化、同结构 | 当前监督 + 积分终点监督；预测通过 ODE 积分 |

Wear 以训练标签均值/标准差标准化；时间 tau=C/1000；rate 是 d(zVB)/d(tau)，softplus 保证非负。RK4 固定 20 步，开发侧核对 40 步数值差异。两个辅助损失系数固定 1，AdamW lr=1e-3、weight_decay=1e-4，CPU 单线程初测。各训练损失先刀具内平均，再刀具等权，避免 M2 记录更多而主导优化。Local 的偏导保持 sensor 特征固定，不等于沿真实 sensor 轨迹的全导数。

没有 ODE 预训练或 NASA 权重迁移。固定 100 epoch；正式保存 epoch 0–100 的当前/未来/发布标签初值预测，train/validation/test 分列。测试不参与选择。Current-only 不报告未经学习的 rate 传播。

计划神经网络 4 类 × 9 折 × (1 内层 seed0 + 5 最终 seed) = 216 次；GPR 18 个确定性拟合，不人为复制五 seed。GPR 是普通 GPR，非 PI-GPR：Constant×RBF+White，训练边际似然优化、无重启；训练每刀按时间均匀最多 128 条，明确报告子采样预算（最多 1024 条），测试全覆盖。没有测试挑核函数。

统计以 9 把刀为单位，五 seed 先平均；报告刀具宏平均和逐刀结果，另列记录加权结果及每个 horizon 覆盖。S3 oracle 增量误差和 oracle 终点误差数学相同，不计作两份独立证据。所有标签来自同一插值发布流程，九刀也不是九种独立工况。

## 运行顺序

1. base Anaconda python 执行 prepare_features.py（含 h5py）；写 features.npz、records.csv、sensor_quality.csv、feature_audit.json。
2. CondWear-ODE python 执行 data_protocol.py；写 18 个训练内 scaler/排名、因果目标、配对和覆盖、划分清单。
3. CondWear-ODE python 执行 smoke_test.py --epochs 3；仅 T1–T7 训练/T8 验证，不计算 T9 测试性能；写 smoke/epoch_metrics.csv、audit.json 和重载用模型。

正式 runner 与最终汇总在 smoke 通过后落实；本 README 不代表正式训练已完成。准备与训练源码分离，特征源码哈希与档案 SHA256 留存。
